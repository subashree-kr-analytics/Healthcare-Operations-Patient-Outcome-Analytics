# 🏥 Healthcare Operations and Patient Outcome Analytics Report (Power BI)

## 📌 Project Description
This project is a Power BI healthcare analytics report developed to analyze hospital operations, patient outcomes, doctor performance, treatment effectiveness, and financial performance.  
The report provides interactive visual insights to support healthcare decision-making and operational improvements.

---

## ⚙️ Features
- 📊 Executive healthcare overview dashboard
- 👨‍⚕️ Doctor and treatment performance analysis
- 🧑‍🤝‍🧑 Patient insights and demographic analysis
- 💰 Financial and operational performance tracking
- 📈 Interactive KPI monitoring and trend analysis
- 🏥 Hospital operations analytics

---

## 🧑‍💻 Technologies Used
- Power BI
- DAX
- Excel Dataset
- Data Visualization
